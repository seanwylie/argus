# Operating Principles

Canonical index: [`README.md`](README.md) in this folder. These bullets are the **short rule list** agents should not violate without explicit intent.

- Temporal data provides current reality.
- Advisors provide interpretation, not truth.
- Decisions must expose confidence, uncertainty, and risk.
- Most restrictive autonomy rule wins.
- Degraded paths must warn, not fail silently.
- Stubbed capabilities must reduce confidence only when relevant.
- External-impact actions remain gated until explicitly enabled.
